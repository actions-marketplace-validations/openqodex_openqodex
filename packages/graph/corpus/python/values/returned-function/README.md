pick(k) returns on_a or on_b by name. run calls `pick(k)()`; later assigns `h = pick(k)` once and calls h(). The change edits on_a. Neither call names on_a, so a graph that binds only named calls reports no caller. Because pick's body returns on_a and on_b, both calls may run either: each must be a possible may_invoke edge to on_a and on_b at the call line, beside the certain calls to pick, and the returned names are certain uses_value references.

shop/api.py imports with_tax through a relative import (`from .prices import with_tax`) and also calls json.dumps from the standard library. A change to with_tax must list quote as a certain caller. The json.dumps call is the trap: a graph that cannot tell a standard library module from a missing in-repo module reports it as an unresolved in-repo call, which marks the caller list of everything named dumps as a floor and fills the brief with a false gap. The call must count as external.

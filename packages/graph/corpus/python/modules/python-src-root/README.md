Two Python projects in one repository, each with its own pyproject.toml and a src layout: pkgs/a/src/alib and pkgs/b/src/blib. blib/use.py does `from alib import shared` and calls shared.compute. Neither the repository root nor pkgs/b holds alib, so a graph that resolves absolute imports only from the root or from the importer's own folders finds no module and loses the caller of compute. The import must resolve through the other project's src root, and the caller must bind.

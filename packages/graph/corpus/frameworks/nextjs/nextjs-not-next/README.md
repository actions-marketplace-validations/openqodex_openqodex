A component library that declares next but is no Next.js application: its `page.tsx` sits in `lib/app` and its `Home.tsx` in `components/pages`, neither of them the project's router root, and its `lib/save.ts` holds the string "use server" after an import and again after the first statement of a function, where Next.js reads no directive. A plugin that matched a folder name anywhere in a path, or looked for the directive text anywhere, would report a page, a home route and a server action. The case checks that it reports no application, no route and no role.

A Go service that imports net/http as `nethttp`. Its `root` mux mounts the `api.Mux` of package api under `/api/` through `nethttp.StripPrefix("/api", api.Mux)`, mounts a second mux `old` directly under `/legacy/`, mounts `api.Mux` again under a prefix read from an environment variable, and wraps one route in `withAudit`; the health route's pattern is `"GET " + healthPath`, a package constant, and its handler is the method value `s.health`. The api test imports httptest and testing under aliases and requests `GET /api/users/7`, and a second test requests a path built from a variable. The change edits `GetUser`. A route graph that only knows the name `http`, that does not compose a mounted mux, or that binds a request to a route by its pattern as written would miss every route here, or link the request to `GET /users/{id}`, which never sees that path. The case checks that `GET /users/{id}` appears as `/api/users/{id}` on `root`, as written on `api.Mux`, and with no pattern under the computed prefix (an unknown of cause dynamic); that `old`'s `/legacy/report` is composed into `root` while `/elsewhere`, which the `/legacy/` mount never reaches, stays on `old` alone; that the method value binds to `server.health`; and that the request reaches the composed route on one mux, as likely, while the computed request path is an unknown.

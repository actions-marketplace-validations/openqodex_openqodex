# Django: statements the facts do not read are said, never dropped

Guards against routes, test requests, receivers, settings reads and fields lost without a gap: a spread inside an included list, a loop that appends to urlpatterns, a remove and a del on it, a test request whose path is a variable, a receiver whose signal is computed, a settings read with a computed key, and a field set inside an `if` of the class body each leave a gap. An entry appended to a joined list, an inserted entry and a router joined into a list other than urlpatterns are read as routes.

# Rails: models, associations, tables and the migrations that change them

Guards against a model change that loses its schema history. `Post` is a model by its `ApplicationRecord` base; it maps to `posts` by Rails' pluralisation (likely), `User` to `members` by its literal `self.table_name` (certain), `Admin` to `members` by single table inheritance, and `Person` to `people` by the irregular plural. Its associations link to `User` (by `class_name:`), `Comment` and `Tag`; `has_one :cover_image` names a class no file defines, which is a gap. Each migration under db/migrate names its tables, and through them the models; the brief lists the migrations of the touched model and the tables a changed migration changes. Schema is read from declarations only, never from a database.

# Rails: the views an action renders, explicit and implicit

Guards against a view link that is wrong or missing. `render "posts/detail"`, `render :form_page`, `render partial: "card"` (the `_card` partial in the controller's folder), `render partial: "shared/footer"` and `render template: "reports/summary"` each link to their file under app/views; an action that names no template renders its implicit view, in every format that exists (`index.html.erb` and `index.json.jbuilder`); an action that renders another template never links to its implicit view (`show.html.erb`), and a view of the same name in another controller's folder (`admin/posts/detail`) is never linked. A literal name with no file is a template with no file and a gap.

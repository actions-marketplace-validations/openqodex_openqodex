The project declares fastapi and app/main.py imports `Depends` from it, but its application and router are classes of its own in app/web.py, named `FastAPI` and `APIRouter` and imported from there. Every line of app/main.py looks like FastAPI: `app = FastAPI(title="local")`, `router = APIRouter(prefix="/r")`, `@router.get("/inner")` with a `Depends(get_settings)` parameter, `@app.get("/")` and `app.include_router(router, prefix="/nested")`. A plugin that trusted the dependency, the class names or the method names would report two routes, a mount and a dependency. The case has no Pydantic class and no test module, so the plugin must emit no role either. It checks that nothing is reported: a value is a FastAPI application or router only when it is made by calling the fastapi package's own `FastAPI` or `APIRouter`.

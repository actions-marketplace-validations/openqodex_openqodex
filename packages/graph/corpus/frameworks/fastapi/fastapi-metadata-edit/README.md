The base declares no dependency in pyproject.toml, so `@app.get("/ping")` in service/main.py is no route there: the fastapi import resolves to nothing the project declares, and a dependency is what enables the FastAPI rules. The change only adds `fastapi` to the dependencies; service/main.py is unchanged, so its facts come from the cache. A plugin whose output was cached with the file, or that decided from the manifest when it read the file, would still report nothing. The case checks that the application, the route `GET /ping` and its handler `ping` appear once the manifest declares fastapi, with no edit to the file that holds them.

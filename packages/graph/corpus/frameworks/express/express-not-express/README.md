The project declares express and imports a type from it, but its routes live on a `MiniRouter` class of its own, and the value named `app` is made by a local function that happens to be called `express`. Every call looks like Express: `app.get("/", home)`, `router.get("/inner", home)`, `app.use("/nested", router)`. A plugin that trusts the dependency, the method names or the name `express` would report three routes and a mount. The case checks that none is reported: a value is an Express application only when it is made by calling the express module's own export.

The base declares no dependency, so `app.get("/ping", ping)` in src/server.ts is no route there: a dependency enables the Express rules. The change only adds `express` to package.json; src/server.ts is unchanged, so its facts come from the cache. A plugin whose output was cached with the file, or that decided from the manifest at extraction time, would still report nothing. The case checks that the route and its handler appear once the manifest declares express, with no edit to the file that holds them.

A small React application: function components, a class component on `React.Component`, a context with its provider, a hook `useUser` that calls React's `useState` and `useEffect`, a function `useLabel` named like a hook that calls none, a `Picker` that renders whichever component a table lookup gives it, a `Button` imported from a dependency under an alias, a second `Button` in src/other that nothing imports, and a Testing Library test that renders `UserCard`. The change edits `Button`. A component graph that matched elements by name would bind `<Button>` to both buttons and `<View>` to anything, and one that trusted the `use` prefix would call `useLabel` a hook. The case checks that `UserCard` renders the imported `Button` and only that one, that `<View>` is an unknown of cause dynamic, that the provider of a context and the dependency's button bind to nothing, that `useUser` is a hook and the class is a component, and that the test renders `UserCard`.

The project declares react, but nothing in it is React: `Widget` extends a class of the repository that happens to be named `Component` and renders a string, `useCache` and `useTwice` are named like hooks but call a dependency's `useMemoize` and a plain function of their own, and the test calls a `render` function of the repository rather than a testing library's. A plugin that trusted the dependency, the base class's name, the `use` prefix or the name `render` would report a component, two hooks and a test link. The case checks that it reports none.

The base declares no dependency, so `Card` and `Badge` are no React components there, though they hold JSX: a dependency enables the React rules. The change only adds `react` to package.json; the two component files are unchanged, so their facts come from the cache. A plugin whose output was cached with the files, or that decided from the manifest when it read them, would still report nothing. The case checks that both components and the element that renders `Badge` appear once the manifest declares react.

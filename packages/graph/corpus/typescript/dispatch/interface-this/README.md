Service takes its repository as a constructor parameter property, `constructor(private repo: Repo)`, and load calls this.repo.find. Repo is an interface imported with `import type`; SqlRepo and MemRepo implement it. The change edits SqlRepo.find. A graph that types this.repo only from assignments in the class body, or never reads parameter properties as fields, loses the receiver type and reports no caller (the audit's miss A). The call must bind certain to Repo.find through the field type, reach both implementations as possible dispatches_to callers with a dispatch record, and leave the unsupported-rule unknown every call through a TypeScript interface leaves.

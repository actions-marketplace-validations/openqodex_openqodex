`memoryRepo` is a module-level object literal typed `Repo`, so it implements the interface by its declaration, and `load` calls `find` through a parameter typed `Repo`. The change edits `memoryRepo.find`. A graph that indexes an object literal's methods only for calls on the literal itself never reaches them from a call through the interface, and reports the edited method with no caller and no floor. The call must bind certain to `Repo.find`, reach `memoryRepo.find` as a possible caller with the dispatch record naming it, and the literal must implement `Repo` and its method override `Repo.find`.

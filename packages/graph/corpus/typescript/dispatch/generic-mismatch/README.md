Repo<T> declares find(): T. UserRepo implements Repo<User>, OrderRepo implements Repo<Order>, and GenericRepo<T> implements Repo<T>. firstUser takes `r: Repo<User>` and calls r.find. The change edits UserRepo.find. TypeScript compares User and Order by their shapes, not their names, so an OrderRepo can be a Repo<User> when Order has every member User has; the graph does not hold every property of a type, so it cannot prove they differ. A graph that drops OrderRepo.find because the names differ can hide the implementation that runs. The call must reach all three implementations as possible dispatches_to callers.

Options is an exported interface. configure takes `opts: Options`, defaults returns `Options`, and parse casts with `as Options`. The change edits a property of Options. None of these sites is a call, so a graph that only follows calls reports that the change reaches nothing, while every one of them may stop compiling. Each must be a uses_type reference from its enclosing function to Options, certain because Options is imported, at the line that names it.

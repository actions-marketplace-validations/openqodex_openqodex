BaseRepo is an abstract class whose find is declared `abstract`; SqlRepo and MemRepo extend it and define find. run takes `repo: BaseRepo` and calls repo.find. The change edits SqlRepo.find. A graph that binds the call only to BaseRepo.find, which has no body, tells the reviewer that nothing runs SqlRepo.find (the audit's miss O). The call must bind certain to the declared member BaseRepo.find, reach both overrides as possible dispatches_to callers, and keep a dispatch record whose candidates are exactly the two overrides: an abstract member never runs, so it is never a candidate.

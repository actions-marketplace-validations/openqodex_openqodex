packages/app declares @acme/core as ^1.0.0, and pnpm-lock.yaml resolves that importer's @acme/core to the published version 1.0.0, not to a workspace link. The workspace still holds a package named @acme/core. A graph that binds by name alone would list packages/app as a caller of the workspace greet, a false edge to code the app never runs. The call must count as external (a declared dependency), never as a workspace caller and never as an in-repo gap.

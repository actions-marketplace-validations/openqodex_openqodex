packages/web has its own tsconfig.json with a paths entry, @lib/* to src/lib/*, that the root tsconfig.json does not have. TypeScript reads the nearest tsconfig for a file, so page.ts's import of @lib/dates is the source file packages/web/src/lib/dates.ts. A graph that reads only the root tsconfig treats @lib/dates as an unknown package, and a change to formatDate shows no caller. The aliased caller must bind as certain through the package-local mapping.

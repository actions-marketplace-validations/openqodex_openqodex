wrap(fn) returns `(...a) => fn(...a)`: it does not call fn itself, the closure it defines does. start calls `app(wrap(handler))`. The change edits handler. A graph that reads only the top level of wrap's body sees no call of fn and drops the edge, so handler reads as unused by start. A parameter called inside a nested function counts, so start must be a possible caller of handler through a may_invoke edge at the argument's line, and the argument a certain uses_value reference.

pick(k) returns onA or onB by name. run calls `pick(k)()`, and later writes `const h = pick(k)` and calls h(). The change edits onA. Neither call names onA, so a graph that binds only named calls reports no caller. Because pick's body returns onA and onB, both calls may run either: each must be a possible may_invoke edge to onA and onB at the call line, beside the certain calls to pick, and the returned names are certain uses_value references.

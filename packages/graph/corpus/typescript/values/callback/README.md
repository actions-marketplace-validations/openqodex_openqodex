each(items, cb) is defined in the repository and calls cb for every item. main calls `each(xs, helper)`. The change edits helper. Nothing calls helper by name, so a graph that follows only named calls says helper has no caller, yet each runs it for every element. Because each's body calls its parameter cb, main must be a possible caller of helper through a may_invoke edge at the argument's line, and the argument must be a certain uses_value reference.

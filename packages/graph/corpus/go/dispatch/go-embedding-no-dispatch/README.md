Inner.Run calls its receiver's M, and Inner defines M. Outer embeds Inner and defines its own M. The change edits Outer.M. Embedding is not inheritance: when Run is called through an Outer, its receiver is still the embedded Inner, so i.M() always runs Inner.M. A graph that treats embedding like a subclass lists Run as a possible caller of Outer.M. The call must bind certain to Inner.M, never reach Outer.M, and leave no unknown; Outer.M has no caller and its list is complete.

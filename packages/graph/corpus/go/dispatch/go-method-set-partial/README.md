Store declares Get and Put. Full defines both; Half defines only Get. Read takes `s Store` and calls s.Get. The change edits Half.Get. A Half can never be a Store, so a graph that matches on the one method called, or on any shared name, lists Read as a possible caller of Half.Get and Half as an implementation of Store. The call must bind certain to Store.Get and reach only Full.Get; Half implements nothing and Half.Get is never reached from Read.

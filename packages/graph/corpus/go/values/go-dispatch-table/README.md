route.go declares `var handlers = map[string]func(string) string{"a": handleA, "b": handleB}` and Route calls `handlers[k](x)`. The change edits handleA. The index call has no name to bind, so a graph without value tracking only reports a gap that could reach any function of the project. Because handlers is a map literal in the same file, the call may run exactly its values: Route must be a possible caller of handleA and handleB through may_invoke edges, each value a certain uses_value reference, and the dynamic unknown must stay at the call. Its scope stays the project: handlers is a package-level variable that any file of the package may change, so a function it never named may be called.

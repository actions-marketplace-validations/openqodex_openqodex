util.Each(xs, cb) calls cb for every element. Package app calls `util.Each(xs, Show)`. The change edits Show. Nothing calls Show by name, so a graph that follows only named calls says Show has no caller, yet Each runs it for every element. Because Each's body calls its parameter cb, Main must be a possible caller of Show through a may_invoke edge at the argument's line, and the argument a certain uses_value reference.
